# Workflow & Execution Guidelines

## 1. Otonomi & Konfirmasi
- Untuk proses instalasi dependensi, editing file, create file, dan build/update (seperti `npm install`, `npm run build`, `npm run dev`), **jalankan langsung tanpa meminta konfirmasi berulang kali**.
- Selesaikan tugas end-to-end secara mandiri sampai tuntas tanpa terhenti di setiap langkah kecil.

## 2. Git Commit & Push Policy (PENTING)
- **Git Commit**: Saat seluruh perubahan sudah selesai dan siap di-commit, **TANYAKAN DAN MINTA KONFIRMASI terlebih dahulu kepada pengguna**. Tampilkan daftar file yang diubah dan pesan commit yang diusulkan.
- **Git Push**: **JANGAN PERNAH menjalankan `git push` secara otomatis**. Selalu tunggu perintah eksplisit dari pengguna.
